# לירן אוזן – טרקטורים ומעמיסים חקלאיים

אתר תדמית ומכירות: מלאי כלים עם סינון, עמוד לכל כלי, טפסי פנייה, WhatsApp צף וממשק ניהול.

## הפעלה מקומית

```bash
npm install
ADMIN_PASSWORD=סיסמה-ארוכה npm start
```

האתר עולה בכתובת http://localhost:3000, וממשק הניהול בכתובת http://localhost:3000/admin.

## ממשק הניהול (`/admin`)

- **כלים:** הוספה, עריכה ומחיקה של כלים, העלאת כמה תמונות בבת אחת, סידור התמונות (הראשונה היא הראשית) וסימון כלי כ"נמכר" או "בתהליך מכירה".
- **פניות:** כל טופס שנשלח מהאתר (צור קשר, הצעת מחיר, מכירה, טרייד אין) מגיע לכאן, עם קישור לחיוג ול-WhatsApp.
- **המלצות:** הוספה ועריכה של המלצות לקוחות.
- **תמונות האתר:** תמונה ראשית לדף הבית ותמונה לעמוד אודות.

התמונות מומרות אוטומטית ל-WebP בשני גדלים, כדי שהאתר ייטען מהר גם בנייד.

## המלאי ההתחלתי

המלאי נלקח מהמודעות של לירן באתר machine.co.il, עם התמונות, ונשמר בתיקייה `seed/`.
בהפעלה הראשונה, כשעוד אין נתונים, השרת טוען את המלאי הזה אוטומטית. מאותו רגע מנהלים את המלאי רק דרך ממשק הניהול.

כדי לייבא מחדש מהמודעות (זה מעדכן רק את `seed/`, לא את הנתונים החיים):

```bash
node scripts/import-machine.js
```

## משתני סביבה

ראו `.env.example`. חובה להגדיר `ADMIN_PASSWORD`. בלעדיה ממשק הניהול נעול.

## אחסון

האתר הוא שרת Node.js (גרסה 18 ומעלה). הנתונים נשמרים בקבצי JSON בתיקייה `data/`, והתמונות בתיקייה `uploads/`.
בשרת הייעודי צריך דיסק קבוע לשתי התיקיות האלה, למשל Render עם Persistent Disk, Railway עם Volume, או שרת VPS.
באחסון בלי דיסק קבוע, הכלים והתמונות יימחקו בכל פריסה.

## מבנה הקוד

- `server.js`: נתיבים לאתר ולממשק הניהול
- `lib/`: אחסון נתונים, תמונות, התחברות ופרטי העסק (`lib/site.js`: טלפון, כתובת וקטגוריות)
- `views/`: תבניות העמודים
- `public/`: עיצוב, סקריפטים, פונטים ולוגו
